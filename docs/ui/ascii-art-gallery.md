## Usage Notes

1. **Font:** These designs work best with monospace fonts (Fira Code, JetBrains Mono, etc.)

2. **Colors:** Pair with appropriate crossterm colors:
   - Title/Important: Yellow, Gold
   - Danger: Red
   - Info: Cyan, Grey
   - Success: Green

3. **Testing:** Always test in target terminal emulator to verify rendering

4. **Fallback:** Keep plain ASCII alternatives for terminals with limited Unicode support
